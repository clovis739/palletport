# Goldstack catalog import

The public WooCommerce catalog contained 98 products on 2026-10-02. All records include USD prices, descriptions assembled from published product facts, available condition and assortment details, and locally stored galleries. Source attribution stays internal; public listings use PalletPort SKUs generated by the database.

Quantities are exact only when explicitly stated as exact unit counts. Approximate quantities and ranges remain in descriptions. Pallet and gaylord counts are separate from unit counts. Unknown shipping locations, weights and conditions are not invented. Supplier claims about profits and authenticity are omitted. Published stock availability represents one offered lot when an exact stock count is unavailable.

Commands:

```powershell
npm run catalog:fetch-goldstack
node scripts/localize-product-images.mjs --goldstack
npm run catalog:check-goldstack
npm run catalog:import-goldstack
```

Importing matches stable internal GS IDs, preserves existing branded SKUs, and retains other listings. Complete original records and rollback backups are local and excluded from Git. Normalized facts are in prisma/goldstack-products.json. Image and database verification reports are in docs/GOLDSTACK-IMAGE-IMPORT.json and docs/GOLDSTACK-IMPORT-RESULT.json.
